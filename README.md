#Прогноз погоды

Консольная программа на Node.js для получения прогноза погоды через открытый API [Open-Meteo](https://open-meteo.com/).

Получает на вход название города (или несколько через запятую), получает координаты через геокодинг, запрашивает прогноз и сохраняет отчёт в JSON-файл. Все отчеты кэшируются на текущий день.


#Программа имеет следующие возможности:
- Поиск координат города по названию
- Показ минимальной и максимальной температуры, а также осадков в интервале от 1 до 7 дней
- Программа поддерживает параллельную обработку через `Promise.all`
- Повторный запуск в тот же день читает данные из файла без сети благодаря кэшированию
- Понятные сообщения об ошибках
- Программа имеет жёсткое ограничение времени запроса через `AbortController`

#Технические требования

**Node.js** - 20 или выше (нужен встроенный `fetch`, `parseArgs`, `AbortController`) 
**npm** - 9 или выше 
**ОС** - Windows / macOS / Linux 

Проект имеет следующие модули:

index.js	Разбор CLI, запуск, коды выхода
api/weather-client.js	Сетевые запросы, таймауты, парсинг JSON
services/weather-service.js	Связь API + кеш
storage/cache.js	Файлы, имена, валидность кэша
format/formatter.js	Вывод в консоль
utils/errors.js	Типы ошибок и коды завершения

Использованные инструменты:

Встроенный fetch — без сторонних HTTP-клиентов (axios и т.п.)

AbortController — жёсткие таймауты запросов

util.parseArgs — разбор CLI-аргументов

fs/promises — асинхронная работа с файлами

dotenv — загрузка переменных окружения из .env
